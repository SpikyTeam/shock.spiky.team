# shock.spiky.team

The personal page published at [shock.spiky.team](https://shock.spiky.team),
built and deployed by GitHub Pages.

The page is static: the name, handle and avatar are part of the HTML. That
means the old server-side profile refresh is gone and the page only changes
when its source changes — `shock/` in
[SpikyMC-Sites](../SpikyMC-Sites), assembled by that repository's
`.github/workflows/pages.yml`. GitHub Pages does the building here, so this
repository has no workflow of its own.
